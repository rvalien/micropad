# Распиновка nice!nano v2 (nRF52840)

Результаты практической прозвонки всех GPIO + теста ADC.
**Дата:** декабрь 2025 · **Плата:** nice!nano v2 (nRF52840)

## Три системы нумерации

- **Надпись на плате** (`006`, `008`, `115`…) — физическая маркировка.
- **Arduino D-номер** (`D0`, `D1`, `D2`…) — удобное обозначение, как в схеме платы.
- **`pinMode()` номер** (`11`, `12`, `3`…) — число, которое нужно передавать в `pinMode()`, `digitalRead()` и `analogRead()` в коде.

> В скетчах используются именно номера из колонки `pinMode()`.

### О колонке ADC

У nRF52840 аналоговые входы SAADC — только `AIN0`–`AIN7`: P0.02–P0.05 и P0.28–P0.31. Пины порта P1 (`P1.xx`) аналоговых функций не имеют. В прежней версии таблицы ADC был отмечен у D10, D15 и D18 — это неверно, здесь значения исправлены по документации чипа. Среди выведенных на плату пинов ADC поддерживают только **D19 (P0.02)**, **D20 (P0.29)** и **D21 (P0.31)**.

## Нерабочие пины

Через стандартное Arduino API **не работают**:

- D6 (P1.00), D8 (P1.04), D9 (P1.06), D14 (P1.11), D15 (P1.13)
- D10 (P0.09)

Причина не установлена. Возможные объяснения (гипотезы, не проверены):

- У P1.xx в используемом варианте ядра другая нумерация, чем предполагалась при тестировании. Фактическая таблица соответствия задаётся массивом `g_ADigitalPinMap` в `variant.cpp` вашего ядра — стоит свериться с ним.
- P0.09 и P0.10 по умолчанию настроены как выводы NFC; для работы в качестве GPIO их нужно перенастроить в UICR. Здесь P0.10 (D16) при этом работает, а P0.09 (D10) нет, так что вопрос остаётся открытым.
- Часть пинов может быть занята системными функциями (загрузчик, Bluetooth).

## Калибровка ADC

- В режиме по умолчанию (10 бит, референс 3,6 В) при питании 3,3 В максимум составляет **≈ 938**, а не 1023: `3,3 / 3,6 × 1023 ≈ 938`. Это согласуется с измеренными ~940.
- Для перевода в проценты используйте `map(value, 0, 938, 0, 100)`.
- При изменении `analogReference()` или `analogReadResolution()` максимум меняется — эти настройки глобальны и действуют на все каналы.

## Измерение батареи

Встроенный делитель напряжения 2:1. По документации nice!nano напряжение батареи выводится на **P0.04 (AIN2)**. Номер пина для `analogRead()` зависит от варианта ядра — **не подтверждён на железе**, проверьте на своей плате (если в ядре есть макрос `PIN_VBAT`, используйте его).

## Дополнительные порты и системные пины

- **P1.01, P1.02, P1.07** доступны на отдельных контактах, но не имеют Arduino-маппинга: нужна прямая работа с регистрами nRF52840 (для начинающих не рекомендуется).
- **D0/D1** могут конфликтовать с UART.
- Часть пинов P1.xx может быть занята Bluetooth/NFC.
