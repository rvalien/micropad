- **🎚️ Пинов с ADC**: 5 (D10, D18, D19, D20, D21)
- **🎚️ Рабочих ADC пинов**: 4 (D18, D19, D20, D21)

---

## ⚠️ Нерабочие пины

Следующие пины **НЕ работают** через стандартное Arduino API:

- ❌ **D6** (P1.00) - пин **100** на плате
- ❌ **D8** (P1.04) - пин **104** на плате
- ❌ **D9** (P1.06) - пин **106** на плате
- ❌ **D10** (P0.09) - пин **009** на плате
- ❌ **D14** (P1.11) - пин **111** на плате
- ❌ **D15** (P1.13) - пин **113** на плате

**Причина**: Вероятно, эти пины заняты системными функциями (Bluetooth, NFC, и т.д.) или не полностью выведены в Arduino Core для nRF52840.

## ✅ Рекомендуемые пины для проектов

### 🎮 Для кнопок (цифровой вход):

- **D0** (008), **D1** (006), **D2** (017), **D3** (020), **D4** (022)
- **D5** (024), **D7** (011), **D16** (010)
- **D18** (115), **D19** (002), **D21** (031)

### 🎚️ Для потенциометров/сенсоров (аналоговый вход):

- **D20** (029) - ⭐ **ЛУЧШИЙ** (самые стабильные показания ADC)
- **D19** (002) - хороший
- **D21** (031) - хороший
- **D18** (115) - приемлемый

## 🔍 Важные замечания

### Путаница в нумерации:

1. **Пин "010" на плате** → это **D16**, НЕ D10!
2. **Пин "009" на плате** → это **D10** (но он не работает)
3. **Пин "115" на плате** → это **D18**, НЕ какой-то другой номер

### Три системы нумерации:

- **Надпись на плате** (006, 008, 115...) - физическая маркировка
- **Arduino D-номер** (D0, D1, D2...) - используется в коде Arduino
- **pinMode() номер** (11, 12, 3...) - внутренний номер для функций

### Калибровка ADC:

- Максимальное значение ADC: **~940** (не 1023)
- Для достижения 100% используйте: `map(value, 0, 940, 0, 100)`

### Дополнительные порты (без Arduino маппинга):

- **P1.01**, **P1.02**, **P1.07** - доступны на отдельных контактах
- Требуют прямой работы с регистрами nRF52840
- Не рекомендуются для начинающих

### Системные пины (избегайте):

- D0/D1 могут конфликтовать с UART (Serial)
- Некоторые пины P1.xx заняты Bluetooth/NFC
